# Security Policy 🔐

## 🧭 Supported Versions

Security fixes are provided for the latest version on the default branch.

## 🚨 Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Report privately to the repository owner with:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Suggested mitigation (if available)

## 🛡️ Response Process

- Initial triage target: within 5 business days
- Status updates: shared during investigation
- Fix timeline: based on severity and exploitability

When a fix is released, affected users should upgrade immediately.
